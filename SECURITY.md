# Sicherheit / Security

## Deutsch

### Unterstützte Version

| Version | Unterstützt |
|---|---|
| 1.0.x | ja |
| älter | nein |

### Eine Sicherheitslücke melden

Bitte **nicht** als öffentliches Issue. Nutze stattdessen die private
Meldung von GitHub: im Repository den Reiter **Security**, dann
**Report a vulnerability**. Die Meldung sieht nur, wer das Projekt betreut.

Eine erste Antwort ist innerhalb von **7 Tagen** zu erwarten. Wird die Lücke
bestätigt, folgt ein Fix in einer neuen 1.0.x-Fassung; die Meldung wird
danach gemeinsam mit dem Fix offengelegt.

### Bitte keine echten Personendaten

MASCHERA verarbeitet Dokumente mit Personendaten. **Hänge keine echten
Dokumente und keine echten Personendaten an eine Meldung.** Eine
erfundene Probe, die den Fehler zeigt, genügt.

## English

### Supported version

| Version | Supported |
|---|---|
| 1.0.x | yes |
| older | no |

### Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private reporting
instead: open the **Security** tab of the repository, then **Report a
vulnerability**. Only the maintainers can see the report.

Expect a first answer within **7 days**. If the vulnerability is confirmed,
a fix follows in a new 1.0.x release, and the report is disclosed together
with the fix.

### Please send no real personal data

MASCHERA processes documents that contain personal data. **Do not attach
real documents or real personal data to a report.** An invented sample that
shows the problem is enough.
