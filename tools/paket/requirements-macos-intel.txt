# numpy holt der Workflow vorab als Rad fuer macOS 13 (`--platform`), sonst
# nimmt pip auf dem macOS-15-Runner das Rad fuer macOS 14. Dependabot
# ist dafuer angewiesen, keine hoehere Fassung vorzuschlagen
